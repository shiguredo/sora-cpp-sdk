# ステレオ音声を受信していることが判断できるようにする

- Created: 2026-09-11
- Completed: {YYYY-MM-DD}
- Branch: feature/add-stereo-receive-detection
- Polished: {YYYY-MM-DD}

## 目的

Sora C++ SDK でステレオ音声を受信しているかどうかを判断できる仕組みを用意する。ステレオ音声の受信対応 (0082) の検証に必要となる。

## 現状

- `src` / `include` にステレオ音声の受信を判断する仕組みはない
- `examples/sumomo` にステレオ受信を判定するログやオプションはない
- 受信した音声がステレオかどうかは、左右差が分かる音声 (ステレオマイクやステレオ音声ファイル) を受信して耳で判断するしかない
- ステレオ音声の受信対応は 0082 で扱っており、本 issue はその判断手段を用意する

## 設計方針

- 左右の音声の取得方法を検討する
- 左右で違う音声が流れていることを判断する方法を検討する (左右の diff の計算など)
- 出力方法を検討する (sumomo のログに出す、など)
- 判定を SDK の API として提供するか、検証用の仕組みとして sumomo に閉じるかを決める

## 完了条件

- ステレオ音声を受信しているかどうかを判断できること
- 判断に使った手順と結果が issue に記録されていること

## Pending 理由

- ステレオ音声の受信対応 (0082) が pending であり、受信自体ができる状態になっていない
- 左右差の判定方法と出力方法の設計判断が必要

## Pending 解除条件

- ステレオ音声の受信対応の見込みが立ち、判定方法と出力方法の方針が決まったこと
